bagging -> bootstrap aggregation
Instead of trusting one model, train many models on different subsets of the data and combine their predictions.

Think of it like asking multiple experts instead of relying on just one.
Ask 100 people
Friend A   ⭐⭐⭐⭐⭐
Friend B   ⭐⭐⭐⭐
Friend C   ⭐⭐⭐⭐⭐
Friend D   ⭐⭐⭐⭐
...

Now you take the majority opinion.

This is much more reliable.

Bagging works exactly like this.

WHY WE NEED BAGGING
Suppose we train a Decision Tree.

Training Data
      │
      ▼
Decision Tree
      │
Prediction

Decision Trees have high variance.

Small changes in the training data can produce a very different tree.

Example:

Dataset 1
      Root
     /    \
   Age   Salary
Dataset 2 (slightly different)
      Root
     /    \
 Income   Experience

Even though the datasets are almost the same, the trees are very different.

This makes Decision Trees unstable.

Bagging reduces this instability.

HOW BAGGING WORKS
Step 1: Original Dataset
1000 samples

Step 2: Create Bootstrap Samples
Instead of using the original dataset once,
Bagging creates multiple new datasets by sampling with replacement.
Example:

Notice:
Some records repeat.
Some records are missing.
=> This is called Bootstrap Sampling.

Step 3: Train Multiple Models
Dataset 1 → Tree 1
Dataset 2 → Tree 2
Dataset 3 → Tree 3
Dataset 4 → Tree 4

Instead of one Decision Tree,
you now have many.

Step 4: Combine Predictions

Classification
Take Majority Voting.

Example:
Tree 1 → Cat
Tree 2 → Dog
Tree 3 → Cat
Tree 4 → Cat
Tree 5 → Dog
Prediction:
Cat
because Cat gets more votes.

Regression
Take the Average.
Example:
Tree 1 → 220
Tree 2 → 210
Tree 3 → 225
Tree 4 → 215
Average = 217.5

WHY BAGGING WORKS, WHY IT IS IMPROVING MORE ACCURACY
--->>> this mainly because of bais variance trade off
-->> in machine learning we need low bias, low varinace model (LBLV)
=> bias -> if training data is giving bad result it means we have high bias
=> variance -> Small changes in the training data can produce a very different tree, this is variance
--> in general bias and variance is  -vely corelated => if bias inc, variance dec
-> we don't get LBLV

-->> but with we can bagging achieve LBLV
-->> algo like deep tree DT(max_depth = None), SVM,KNN => all are following LBHV
-->> bagging is lowering this variance by distributing the impact
